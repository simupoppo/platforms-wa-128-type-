幅狭盛土・構内踏切拡張セット
for simutrans pak128.japan/pak128

wa様が作成されたプラットフォームを拡張するアドオンです。

3つのpakファイルを追加すると、合計で20個のアドオンが追加されます。
ja.tabファイルをpakフォルダ＞text内に配置することで、マウスホバーにより詳しい説明が確認できます。

幅狭盛土ホーム、マスの中央に踏切が配置されたホーム等が収録されています。
なお、sourceについては一部紛失してしまったものがある関係で、sourceファイル内のデータから元のpakを生成することができません。ご注意ください。

幅狭盛土接続ホームについては、使い方に癖があります。
※踏切が中央に来るホームのアイコンには、オレンジ色の枠と「C」が描かれています。
ホーム端に構内踏切中央のホームを設置すると確実にオーバーランします。
OTRP等の指定した場所に停車する機能を使うとはみ出さずに止めることができます。

内容　
・構内踏切のみ（手前）／（中央）
・幅狭盛土ホーム
・幅狭盛土ホーム＋踏切（手前）／（中央）
・幅狭盛土接続ホーム
・幅狭盛土接続ホーム＋踏切（手前）／（中央）
・屋根なしホーム＋踏切（中央）
・壁付屋根なしホーム＋ホーム途中用踏切（中央）
・壁付屋根なしホーム＋ホーム端用踏切（中央）
・壁付屋根なしホーム＋スロープのみ（中央）
・盛土ホーム用駅舎（１マス）／（２マス）
・透明ホーム
